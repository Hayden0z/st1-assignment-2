What did you build before using AI?
I built a simple program where you input the patient name, practitioner name, and the date and time of the appointment. The program then prints the details using a formatted string. I repeated the process a second time to show that two different appointments could be booked.

What did AI help you understand?
The AI helped me understand the opposite of normal if statements — specifically how if not works to check for empty or missing values.

 Did AI make assumptions?
Yes AI assumed the program should stay simple and avoid complex features. That the inputs and outputs should not be inside functions so missed that key input requirement and that storing appointments in a list with  validation was ok. 

 How did you verify the AI output?
I verified the AI’s output by running the code myself and checking that it behaved as expected.

What engineering work remained for you?

testing the program with different inputs and checking for errors and making sure the functions worked  correctly. I also had to write the reflection, add comments, etc. There is still a lot more to do to this code to make it fully functional but it said keep it simple.
